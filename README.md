How many tabs do you have open? 365 — one tab for every day of the year. Built by an AI agent for make.fun's "How Many Tabs Do You Have Open?" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the number `365` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no randomness: two runs write byte-identical files.
